从这里开始，让房间拥有自己的旋律。

准备 Python 与本地推理依赖，另需约 10–15 GB，建议预留 25 GB。修复时保留旧环境备份，模型和曲库会保留。

允许读取本机内存与 NVIDIA 显存容量？信息只留在本机。需要 Windows x64、16 GB 内存和 4 GB NVIDIA 显存。

安装位置与连接信息

连接 GitHub、PyPI、PyTorch 和 Python 下载服务。日志保存在运行环境的 .log/runtime-install.log。可以关闭窗口，稍后重新打开重试。

想使用 Stable Audio 3？先准备访问权限。

设备达到本应用的 SA3 门槛。请先登录 Hugging Face，在模型页阅读条款并申请访问，确认已获准后再下载。登录本身不代表授权；也可以稍后只选择 ACE。

模型设置时可使用本机 HF 登录或有该模型读取权限的 Token，Token 不写入应用配置。
