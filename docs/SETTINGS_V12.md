# 0.12 · 三层设置、统一保存与屏幕背光

## 页面与保存边界

首页、房间设置、高级设置是三个连续的全屏页面。滚轮在可滚动内容的边界才触发翻页，一次连续手势只进入一层；反向手势可以打断动画。按钮、Page Up / Page Down / Escape 也沿相同路径。位置用带速度状态的弹簧更新，最终落在整屏位置。

高级设置的六个标签共享一份草稿：配比与图钉、配方、容量和生成参数、素材保存目录、待导入素材。切换标签或曲风不提交草稿。底部「保存设置」统一提交，放弃则重新载入上次保存的配置。离开页面或关闭窗口时检测未保存内容，页面向上试探、回弹，再询问保存、放弃或继续编辑。

屏幕亮度是即时硬件预览：保存保留，放弃恢复该次编辑之前的亮度。设备扫描、模型下载和曲库迁移为明确标注的独立操作；下载或迁移前先处理设置草稿。导入失败时，已提交的配置保持生效，未导入文件留在列表里，可取消或重试。

`PUT /configuration/save` 先完整验证，再原子替换 JSON 并事务更新 SQLite 设置镜像。内容修订值防止覆盖其他操作已更改的配置。配方存在生成队列冲突时，全部普通配置保持原样，UI 保留草稿供稍后保存；容量等独立调整不受生成队列限制。保存立即生效，新配方用于后续生成任务，无需重启。

## 材质与动效

六个标签使用独立玻璃胶囊与连续滑动的选中光层。面板交接同时退出、进入，卡片依次浮起；快速切换时取消旧动画，从当前视觉状态接续。开关保留原生键盘行为，使用自绘玻璃轨道和带弹性的滑块。

容量设置只放在高级设置「播放与屏幕」。简单设置中保留容量实际用量显示，放大高级设置入口。窄窗口保持固定导航和保存区，内容单独滚动；减少动态效果模式使用短淡入淡出。

图标由白色圆形和深色上半圆组成，带 16–256 像素 ICO、PNG 和界面 SVG。窗口、首次安装窗口和 Windows EXE 都使用这套图标。

## 亮度修复

1. 旧发行包将 PowerShell 脚本打进 ASAR，却把 ASAR 内路径交给外部 PowerShell；外部进程无法按普通文件读取。
2. 原先把脚本执行失败显示为「不支持 WMI」，隐藏了真实故障。
3. 本机 WMI 成功设置亮度时，方法返回空结果；不能把缺少 ReturnValue 当作非零失败。

现由 Electron 读取可信脚本，使用 UTF-16 编码命令交给隐藏的 PowerShell 执行。屏幕 ID、亮度通过独立环境变量传递，不插入命令文本。检测失败与没有支持的屏幕分开显示。成功调用后重新读取实际亮度。

支持可读且可写的 Windows WMI 屏幕；没有加入外接屏 DDC/CI 的虚假支持。
