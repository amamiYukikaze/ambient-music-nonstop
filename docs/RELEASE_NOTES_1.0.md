# 栖声 1.0 — 发布加固

本版保留 Windows x64 / NVIDIA CUDA device 0、本地独立运行环境、有限曲库、QC 首曲门槛、现有场景与界面设计。

- Windows PowerShell 5.1 非交互下载，固定工具与源码哈希；依赖锁定，损坏运行环境进入修复。修复保留旧环境备份，模型和音乐独立保存。
- 配置校验、最后良好副本和损坏原件保留；迁移恢复先于普通设置启动，损坏迁移日志与 Windows 目录联接均有明确处理。
- 首曲失败可在应用创建的空目录重试；QC 成功入库后开启补库，后续主动暂停保持不变。
- IPC 仅接受受信主窗口的主 frame；回调不暴露 Electron 事件，两个窗口均限制导航、新窗口与权限。
- 环境声导入上限 3 分钟，24 kHz 双声道解码、192 MiB 总预算，关闭后释放缓存；并发导入保留全部索引，内置素材缺失/损坏自动修复并保存原件。
- 公开源码由显式允许清单与内容哈希控制；构建从导出树进行，包含完整素材署名。雷声已从显示 CC BY 4.0 的原发布页重新获取并制作。

先核对 ZIP 的 SHA-256，再完整解压运行；不要单独移动 EXE。备份与升级步骤见 [恢复说明](RECOVERY_AND_UPGRADE.md)。声音文件在 `resources/backend/builtin-ambience`，录音许可在发行根目录的 `AMBIENCE_ATTRIBUTION.md` 和 `builtin-ambience/provenance.json`。

发行仍需按 [干净 Windows 验收](CLEAN_WINDOWS_ACCEPTANCE.md)完成标准用户、中文用户名、无预装依赖/无 D: 盘、真实设备播放等测试。当前构建未作代码签名；不得把开发机测试描述成完整干净系统验收。
