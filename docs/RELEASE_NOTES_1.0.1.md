# 栖声 1.0.1 — 首次启动与安装体验

- 首次安装窗口使用完整视口背景；缩放、最大化与日志展开不再产生背景重复或错位。模型向导与安装窗口统一深蓝、暖金的进度样式。
- 默认显示一句当前阶段总览，文字切换约 200 ms；“展开日志”按安装步骤显示原文记录和警告，不翻译、不用概括替换原始输出。展开/收起用可中断的 200 ms 高度与淡入动画。界面保留最近 240 条，完整安装日志保存在运行环境的 `.log/runtime-install.log`。
- 工具/源码归档下载显示实际接收字节数与文件百分比；命中缓存明确显示复用。模型下载、已有文件校验使用实际字节计数。依赖管理器的管道输出仅提供包开始/完成事件，显示这些事件和已完成包数，不推算下载百分比；解压、导入和 CUDA 检查显示活动状态。
- 总步骤计数仅在对应步骤成功后增加，不把等权步骤当作预计耗时百分比；最终健康检查通过才进入应用。启动检查期间有可见窗口。
- 首次设置加入约 1 秒的立鹤与光环入场。按桌面用户配置目录持久记录，安装与模型向导共享一次机会，修复/重启不重复；减少动态效果偏好使用短淡入。
- 发行版运行环境固定在当前应用数据目录的 `runtime`，不再读取旧 `runtime-location.json` 的开发目录指针。旧文件保留，模型与曲库路径继续由原配置管理。开发/测试可显式使用 `AMBIENT_RUNTIME_DIR`。
- uv 使用复制模式，避免跨卷缓存安装反复出现硬链接降级警告；版本锁、摘要和运行环境健康门槛不变。
- 冷安装验证复现 ACE 首次导入超过旧 120 秒限制；每个环境检查改为最多 300 秒、整体最多 720 秒，关闭窗口会结束所属检查进程树。准备窗口关闭到播放器创建之间保持启动流程，避免窗口交接时提前退出。
- 支持 SA3 的设备在安装前即可打开 HF 官方模型页申请授权；模型下载前明确确认访问权限。硬件不达 ACE 最低门槛时阻止运行环境安装；只是不达 SA3 门槛时仍可用 ACE，SA3 在前端与后端均不可启用。确认勾选不会替代 HF 服务器的实际权限检查，未授权时不会开始权重下载。

## 为什么保留一个 EXE

Electron 在 Python 尚未安装时即可显示安装窗口，安装本来就运行在独立 PowerShell 子进程中，完成后由同一入口启动播放器。此次修复针对路径边界、进度协议和呈现层；拆成第二个 EXE 无法自动解决这些问题，反而需要维护两个版本、签名、升级与交接入口。因此 1.0.1 保留一个应用入口和独立安装子进程。
