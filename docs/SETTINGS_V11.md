# 0.11 · 首次设置与独立配置

## 数据与升级

`config.json` 位于应用数据目录，保存曲风配方、用户设置、模型/素材位置、导入素材索引、设备扫描结果及首次设置状态。写入采用临时文件、flush/fsync 和原子替换。SQLite 继续保存曲目、播放次数、任务与日志；设置有兼容镜像，应用重启时以 JSON 设置恢复镜像。曲库路径是例外：有库存时使用迁移事务已提交的数据库路径，防止中断恢复后指向旧库。

已有曲目记录的旧安装会自动接纳现有曲风和设置并跳过向导。不会清空、重编码、重新筛查旧音乐，也不会重置配比、自动补库开关、库地址或内置素材。

新安装默认数据目录为 Electron 用户目录下的 `data`。开发环境可使用 `AMBIENT_DATA_DIR`，模型可存任意用户选定的绝对目录。旧 `D:/AmbMusicNonstop` 安装在检测到其数据库后继续使用。

## 首次启动状态机

无运行环境 → 同意设备检查 → 安装 Python/依赖 → 首次向导 → 同意完整设备检查 → 选择模型及位置 → HF 授权/Token 或校验本地文件 → 下载与校验 → 选择空曲库目录、曲风、百分比 → 提交首曲 → 正式 QC 入库 → 允许进入播放器。

拒绝扫描、设备不足、缺少模型授权、下载失败或首曲失败，都不能进入主播放界面。HTTP `/next`、`/audio`、`/plays`、普通 `/jobs` 也会被首次设置锁定。退出后保留设置、下载分片和任务状态，重启会恢复；失败显示原因，可重试。

支持门槛是本产品当前 Windows CUDA 适配的保守范围，并非上游理论最低配置：ACE Turbo 为 16 GB 系统内存、4 GB NVIDIA 显存；SA3 为 24 GB 系统内存、6 GB NVIDIA 显存。SA3 推理约需 16 GB 可用内存。使用 CUDA 设备 0；其他显卡、操作系统及纯 CPU 新安装暂不开放。设备扫描结果只保存在本机。

下载版本固定；大文件按 HF 清单 SHA-256 校验，分片续传并校验 Content-Range。不把 Token 写入配置、日志或错误提示。配置切换在完整校验成功后发生；下载失败不更改旧模型位置。ACE 的 Python 模型模块由固定源码快照同步，不拿 HF 旧模块长度判定已部署模块损坏。模型位置请选总目录，含 `ace-step/checkpoints`、`stable-audio-3-medium`、`clap`。

## 高级设置

声音分布使用整数百分比、最大余数法分配舍入，总和恒为 100。修改一项时固定项不动，余量按其余未固定项原比例分配；余项全为零时均分；所有余项固定时将当前项夹在唯一可行值。保存固定标志，首次向导复用算法。

配方编辑保存名称、模型、BPM、提示词；完整 JSON 编辑提供配器、情绪、调性、节拍、编码、动态/头尾保留和 shift 等既有参数。模型内部采样使用已经验证的配置，不提供无实现的自由参数。新增自定义风格可以保存；不删除旧风格 ID，停用应通过配比和生成开关完成。正在执行/排队的任务存在时禁止修改配方。

图片导入转为最长 3840×2160 的 WebP，保留名称、环境、时间、曲风和焦点关联；不在自定义图片上绘制灯火/蒸汽。环境声导入转为 Opus，带用户名称、图标并归一化至 -24 LUFS 目标。新保存目录只影响未来导入；原素材注册位置保留。原始导入文件不修改。

双击非控件区域切换全屏。支持 Windows WMI 的内置显示器可调硬件背光；未支持的设备显示不可用，外接屏 DDC/CI 不伪装支持。

## 发布范围与验证

桌面包包括界面、后端源码与内置环境录音，不包括音乐模型、个人曲库和 Python 环境。首次运行可安装依赖，再进入模型下载向导。已有开发环境可由本机数据目录的 `runtime-location.json` 指向；这个文件不进入发行包。

`npm run export:github` 产生允许清单限定的公开源码目录；排除运行配置、HF 凭证、测试库存、试听、日志、个人参考音乐及本机参考音乐 embedding。首次向导的真实首曲验证、桌面截图和自动检查结果保存在开发目录 `artifacts/settings-v11/`，不发布到公开源码。

2026-10-02 本机验证：65 项自动测试通过、1 项跳过；配比算法的 1000 次调整维持总和与固定项；实际 Electron 桌面验证覆盖旧库接纳、首次设置门禁、自定义菜单、配置保存、素材导入、全屏及 WMI 亮度。真实首曲流程生成一首 180 秒 SA3 音乐，经 QC 入库后成功播放；生成中重启恢复也已验证。打包版本验证了自定义图片重启恢复、环境声播放及 980×650 窗口布局。现有生产库升级前后 1270 首可播放曲目、9,936,468,314 字节共享库存与原设置相符。

边界：没有把本机已有运行环境等同于干净 Windows 的完整安装测试；依赖安装脚本已固定源码/主要版本、校验下载和检查导入，但公开宣称广泛兼容前仍需独立干净机器验收。4 GB / 6 GB 硬件门槛不是对所有显卡、驱动及其他并发负载的成功保证。

0.12 更正：0.11 的发行包亮度检查只验证了界面提示，并未验证支持状态与实机调光，因此漏掉 ASAR 路径错误。该问题在 0.12 修复并通过实际调光、读回和恢复验证，详见 [0.12 说明](SETTINGS_V12.md)。
